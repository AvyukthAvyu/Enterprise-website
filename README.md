# Enterprise-website


_******Project Overview******_

This project is a full-stack enterprise web application developed using Python Flask, designed to replicate a real corporate website and recruitment workflow.The platform allows users to explore company information, services, and career opportunities, apply for jobs, and interact with an integrated chatbot.An admin dashboard is implemented to manage applications, review resumes, make selection decisions, and automatically notify candidates via email.


******Key Features******

_User-Facing Features_

Company-style Home, Services, and Careers pages
Job application system with resume upload
Chatbot integration for easy navigation and feature access
Responsive UI using Bootstrap


_Admin Dashboard_

View all job applications in a centralized dashboard
Access candidate details and uploaded resumes
Select or reject candidates directly from the dashboard
Automated email notifications sent to candidates based on selection status

_Analytics dashboard displaying:_

Total number of applications
Total selected candidates
Total rejected candidates


_******Automated Email & API Integration******_

Email APIs integrated for automated communication
Confirmation emails for job applications
Selection and rejection emails triggered by admin actions
REST APIs used for chatbot interaction and backend automation

_******Application Workflow******_

User visits the careers page and applies for a job
Application data and resume are stored in the database
Admin logs into the dashboard
Admin reviews candidate details and resume
Admin selects or rejects the candidate

_System automatically sends:_

Selection email if approved
Rejection email if not approved
Dashboard metrics update in real time


_******Chatbot Functionality******_


API-driven chatbot integrated into the website

_Assists users with:_

Page navigation
Job application guidance
Feature discovery
Improves user experience and accessibility


_******Database Management******_

SQLAlchemy ORM used for structured data handling

_Stores:_

Candidate details
Resume metadata
Application status (Applied / Selected / Rejected)
Ensures consistency and scalability


******Future Enhancements******

Advanced AI chatbot with NLP
